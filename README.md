# Mandelbrot (PiJS)

An interactive Mandelbrot set explorer built with [PiJS](https://pijs.org/).

## Try Online

Link: https://classic.andyswebgames.com/apps/mandelbrot2/

## Run

Open `index.html` in a browser (or serve the folder with any static file server).

## Controls

- **Drag** to select a region and zoom in
- **R** to reset the view

Zoom level is shown in the top-left corner.
